# Python tooling for the model conversion scripts, pinned to the versions
# the bundled models were built with. Newer versions may work; these are
# known to. git must be on the PATH too: convert_modnet.py, convert_isnet.py
# and convert_u2net.py clone their model code at a pinned commit.
#   python3.12 -m venv ~/latent-ml && source ~/latent-ml/bin/activate
#   pip install -r scripts/requirements.txt
#
# Python 3.12, not the python3 macOS ships: that is 3.9, and torch is not
# published for it past 2.8. `pip3` outside a virtual environment is the
# system one, which is the usual cause of "Could not find a version that
# satisfies the requirement torch==2.14.0".
#
# The Core ML half, which the SAM 2.1 sizes need on their own (Apple
# publishes those already converted, so nothing is traced): install
# scripts/requirements-coreml.txt alone for those and skip the rest.
-r requirements-coreml.txt
# Everything below traces a PyTorch model. torch is the tracer itself.
torch==2.14.0
# convert_birefnet.py and convert_segformer.py load their models through
# transformers.
transformers==5.17.0
# convert_birefnet.py's weights are a safetensors file, which transformers
# reads through this.
safetensors==0.8.0
# convert_birefnet.py: the model code BiRefNet ships (birefnet.py, loaded
# through trust_remote_code) imports all of these; kornia only on its
# training path, and torchvision for the deform_conv2d the PyTorch
# reference runs before the grid_sample replacement goes in. The DIS and
# U²-Net model files convert_isnet.py and convert_u2net.py import also
# import torchvision.
torchvision==0.29.0
timm==1.0.29
einops==0.8.2
kornia==0.8.3
